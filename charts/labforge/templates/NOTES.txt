LabForge {{ .Chart.AppVersion }} is installed.

1. Make sure the templates directory on the libvirt host contains your cloud
   images and template.json files:

   {{ .Values.templates.hostPath }}

2. The guest SSH keys come from the Secret "{{ .Values.sshKeys.secretName }}"
   (key "{{ .Values.sshKeys.key }}"). Create it if you have not already:

   kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.sshKeys.secretName }} \
     --from-file={{ .Values.sshKeys.key }}=$HOME/.ssh/id_ed25519.pub

{{- if not .Values.tailscale.secretName }}

3. Tailscale is disabled because tailscale.secretName is empty. To enable it,
   create a Secret and set tailscale.secretName:

   kubectl -n {{ .Release.Namespace }} create secret generic labforge-tailscale \
     --from-file=auth-key=/path/to/your/tailscale-auth-key
   helm upgrade {{ .Release.Name }} . --set tailscale.secretName=labforge-tailscale
{{- else }}

3. Tailscale auth key is mounted from Secret "{{ .Values.tailscale.secretName }}"
   (key "{{ .Values.tailscale.key }}"). LabForge only copies it onto the VM
   seed ISO and never reads or logs it.
{{- end }}

Access the UI:

{{- if eq .Values.service.type "ClusterIP" }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "labforge.fullname" . }} 8899:{{ .Values.service.port }}
   open http://localhost:8899
{{- else }}
   Service type is {{ .Values.service.type }}.
{{- end }}

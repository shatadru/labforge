LabForge control plane {{ .Chart.AppVersion }} is installed.

This release is MODE=control with HOST_MODE=remote. Libvirt must run on a
KVM host via the labforge-agent package, not inside this pod.

1. Install labforge-agent on the hypervisor, set AGENT_TOKEN to the same value
   as Secret "{{ .Values.agent.tokenSecretName }}", and bind the agent on an
   address the cluster can reach (AGENT_BIND must not stay on 127.0.0.1).
   AGENT_URL is {{ .Values.agent.url }}.

2. Guest SSH keys come from Secret "{{ .Values.sshKeys.secretName }}"
   (key "{{ .Values.sshKeys.key }}"):
     kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.sshKeys.secretName }} \
       --from-file={{ .Values.sshKeys.key }}=$HOME/.ssh/id_ed25519.pub

{{- if .Values.auth.enabled }}

3. Login is enabled (Pocket ID + oauth2-proxy). Create the credentials Secret
   ONCE before/after install:
     kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.auth.existingSecret }} \
       --from-literal=ENCRYPTION_KEY="$(openssl rand -base64 32)" \
       --from-literal=STATIC_API_KEY="$(openssl rand -hex 32)" \
       --from-literal=cookie-secret="$(openssl rand -base64 32)"
   The bootstrap job then creates the LabForge OIDC client and fills in
   client-id / client-secret.

   Open Pocket ID at its issuer URL and register the first user (the first
   signup becomes the admin). Afterwards disable open signups:
     helm upgrade {{ .Release.Name }} {{ .Chart.Name }} -n {{ .Release.Namespace }} --reuse-values \
       --set pocket-id.config.ui.settings.app.allowUserSignups=disabled
{{- else }}

3. Login is disabled (auth.enabled=false). Set global.labforge.ingressHost and
   auth.enabled=true, then re-run to put Pocket ID + oauth2-proxy in front.
{{- end }}

{{- if .Values.chat.enabled }}

4. Chat is enabled. LabForge stores one room ("{{ .Values.chat.topic }}") in the
   bundled ntfy subchart, which has no public endpoint.
{{- end }}

Access the UI:

{{- if and .Values.ingress.enabled .Values.global.labforge.ingressHost }}
   https://{{ .Values.global.labforge.ingressHost }}
{{- else if eq .Values.service.type "ClusterIP" }}
   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "labforge.fullname" . }} 8899:{{ .Values.service.port }}
   open http://localhost:8899
{{- else }}
   Service type is {{ .Values.service.type }}.
{{- end }}
